# Portfolio demo script

1. Start stable v1.
2. Generate 100–500 requests and show Grafana latency/request/token panels.
3. Register v2 and send 5% canary.
4. Inject a low quality score or high p95 latency.
5. Show rollback decision in API/PostgreSQL.
6. Inspect Kafka deployment/inference events.
7. Inspect Jaeger trace for the gateway request.
8. Kill a Kubernetes pod and show readiness/recovery.
9. Apply network delay and measure degradation.
10. Run load/soak benchmark and publish measured evidence + RCA.
